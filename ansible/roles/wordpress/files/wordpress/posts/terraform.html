Terraform acts as the Infrastructure as Code (IaC) foundation.

Main features:

  • Network Topology: Provisioning of a dedicated AWS VPC, secure subnets, and internet gateways.
  • Compute Isolation: Deployment of the EC2 instance inside specific Security Groups with custom ingress filtering.
  • SecOps Hardening: Enforcement of IMDSv2 to mitigate SSRF vulnerabilities.
  • Data Protection: Activation of AWS KMS for encrypted gp3 storage volumes and cloud logs.
  • Auditability: Implementation of VPC Flow Logs routed directly to CloudWatch groups.

We decoupled the cloud resources construction from the OS configuration, keeping our infrastructure declarative.

We embedded secure remote state storage to prevent state locking and sensitive data leakage.
